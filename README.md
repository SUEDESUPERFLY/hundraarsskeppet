# Hundraårsskeppet

Ett gemensamt skepp där alla spelare delar samma klocka: en timme i verkligheten är ett dygn ombord. Den som loggar ut lever vidare på rutin tills hen kommer tillbaka.

- `index.html` – hela spelet (Three.js), publiceras via GitHub Pages.
- `supabase/schema.sql` – databasen: tabeller med RLS och funktioner som all åtkomst går genom.

Sololäget finns kvar i samma fil och fungerar även utan databas.
